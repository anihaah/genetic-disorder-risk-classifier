# 🧬 Genetic Disorder Risk Classification System

An end-to-end Machine Learning web application designed to assess and classify genetic disorder risks using Logistic Regression, a Flask backend API, and a Streamlit user interface.

---

## 📌 Project Overview
This project predicts whether a patient is at high or low risk for genetic disorders based on key clinical and demographic attributes such as Age, Blood Pressure, Gene Mutation Score, and Family History.

## 📁 Repository Structure
├── app.py                 # Flask API backend endpoint
├── streamlit_app.py       # Streamlit interactive web interface
├── model.pkl             # Trained Logistic Regression model
├── scaler.pkl            # StandardScaler object for feature normalization
├── requirements.txt       # Dependencies and libraries
└── README.md              # Project documentation
